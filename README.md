# Institutional Research Repository (Frontend)

A modern, responsive web application designed to manage, browse, and search academic research papers across multiple engineering disciplines. Built with React, Vite, Tailwind CSS, and powered by Supabase.

## 🚀 Key Features

- **Multi-Disciplinary Coverage:** Categorized papers across Civil Engineering, Computer Science, Electronics & Telecommunication, Mechanical Engineering, and AI/ML.
- **Accurate Metadata Extraction:** Displays exact paper metadata including primary authors, guide/advisor details, publication years (2010–2025), and publishing venues.
- **Advanced Repository Search:** Real-time filtering by paper title, student author, faculty advisor, department, and exact publication year.
- **Dynamic PDF Storage & Tracking:** Integrated with Supabase Storage for seamless PDF viewing, direct downloads, and real-time download counters.
- **Master-Detail Navigation:** Interactive paper details view featuring abstract summaries, keywords, related publications, and bookmarking.

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Icons:** Lucide React
- **Backend & Database:** Supabase (PostgreSQL, Storage, Realtime API)
- **Routing:** React Router DOM
